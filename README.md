# AAU LaTeX Template
Welcome to this template made by Lukas L Læbel.
This template is inspired by the Aalborg University (AAU) Report Template, made by Jesper Kjær Nielsen and Modified by Andreas Højrup.
as well as inspired by the typst template made by [Sebastian Lorenzen](https://github.com/Naitsabot/AAU-Typst-Template).

## Main Imporvements
- Automatic sections
- Description of functions
- Automatic Preface
- cleaner design
- No Errors by default
- Prettier front page and title page
- Default Zotero integration
- Only needed packages
